# 🌊 АКВА-СТРАЖ

Интеллектуальная система раннего обнаружения неблагоприятных изменений качества воды и состояния гидробионтов для аквакультурных хозяйств Белого моря.

## 📋 Описание проекта

Система мониторинга на основе сети многопараметрических датчиков с применением алгоритмов машинного обучения для обнаружения аномалий в реальном времени.

### Ключевые особенности:
- Непрерывный мониторинг 5 параметров качества воды
- Расчет интегрального индекса риска
- ML-алгоритмы для обнаружения аномалий (Isolation Forest)
- Многоуровневая система оповещений
- Контекстно-зависимые рекомендации операторам

## 🛠️ Технологический стек

- **Backend:** FastAPI, Python 3.9+
- **Frontend:** Streamlit, Plotly
- **ML:** Scikit-learn, Isolation Forest
- **Database:** SQLite
- **IoT:** ESP32, MicroPython (опционально)
